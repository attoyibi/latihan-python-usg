# Berkontribusi

Terima kasih sudah tertarik. Beberapa aturan singkat:

1. Buka *issue* dulu untuk perubahan besar supaya arahnya sama.
2. Kode situs memakai HTML, CSS, dan JavaScript biasa tanpa langkah build. Jangan menambah framework tanpa diskusi.
3. Jangan menaruh kunci rahasia di repositori. Kunci `anon` Supabase boleh (memang publik), kunci `service_role` **tidak boleh**.
4. Jalankan `python tools/validasi_konten.py` sebelum membuka *pull request*. Pemeriksaan yang sama berjalan otomatis di GitHub.
5. Kunci jawaban challenge disimpan di folder `kunci/` yang tidak ikut diterbitkan. Gunakan `python tools/uji_kunci.py` untuk mengujinya.
6. Teks antarmuka berbahasa Indonesia, kalimat pendek, tanpa tanda seru berlebihan.

Panduan menambah bab: [docs/MENAMBAH-BAB.md](docs/MENAMBAH-BAB.md). Panduan mengganti tema: [docs/MENGGANTI-TEMA.md](docs/MENGGANTI-TEMA.md).
