Pemrograman Berorientasi Objek dengan Java

Konsep kelas, objek, pewarisan, dan polimorfisme dengan Java.

Mulai belajar (perlu masuk)

Isi mata kuliah: 15 bab

  1. Bab 1: Paradigma pemrograman berorientasi objek
    Program bisa disusun sebagai kumpulan objek yang memegang data dan perilakunya sendiri. Bab ini membandingkan gaya prosedural dengan gaya objek, dan mengenalkan empat pilar OOP serta ekosistem Java.
  2. Bab 2: Kelas, objek, atribut, method, constructor
    Kelas adalah cetak biru, objek adalah wujud nyatanya. Atribut menyimpan data, method melakukan pekerjaan, constructor menyiapkan objek saat dibuat.
  3. Bab 3: Enkapsulasi dan access modifier
    Data dilindungi dengan private, lalu diakses lewat getter dan setter. Setter yang baik memeriksa nilai sebelum menyimpannya.
  4. Bab 4: Pemodelan dengan diagram kelas UML
    Sebelum menulis kode, rancang kelas dan hubungannya di atas kertas dengan diagram kelas UML.
  5. Bab 5: Pewarisan (inheritance)
    Subclass mewarisi atribut dan method superclass lewat extends, memakai super untuk memanggil bagian induk, dan mengubah perilaku dengan override.
  6. Bab 6: Polimorfisme
    Satu pemanggilan method bisa berperilaku berbeda tergantung jenis objek sebenarnya. Inilah polimorfisme dinamis lewat override dan dynamic binding.
  7. Bab 7: Abstraksi: abstract class dan interface
    Interface adalah kontrak perilaku, abstract class adalah kerangka setengah jadi. Keduanya memaksa kelas turunan melengkapi bagian yang wajib.
  8. Bab 8: Penanganan eksepsi
    Kesalahan saat program berjalan ditangkap dengan try-catch-finally, dilempar dengan throw, dan bisa dibuat khusus lewat custom exception.
  9. Bab 9: Collection framework dan generics
    List, Set, dan Map menyimpan banyak objek dengan cara berbeda. Generics menjaga tipe isinya, Comparator mengatur urutannya.
  10. Bab 10: Operasi berkas dan object persistence
    Data disimpan ke berkas teks atau CSV dan dibaca kembali dengan Path dan Files, lengkap dengan penanganan eksepsi berkas.
  11. Bab 11: Koneksi basis data JDBC dan CRUD
    Program Java berbicara dengan basis data lewat JDBC. PreparedStatement dan pola DAO menjaga kode data tetap rapi.
  12. Bab 12: Antarmuka grafis dan event handling
    Aplikasi berjendela dibangun dari komponen Swing yang ditata layout manager dan dihidupkan oleh event listener.
  13. Bab 13: Prinsip desain SOLID
    Lima prinsip untuk kode yang mudah diubah. Open-Closed, misalnya, menambah perilaku baru dengan menambah kelas, bukan mengubah kelas lama.
  14. Bab 14: Pengantar design pattern
    Pola desain adalah resep yang sudah teruji. Singleton menjamin satu instance, Factory Method memusatkan pembuatan objek, MVC memisahkan data, tampilan, dan pengendali.
  15. Bab 15: Integrasi konsep dalam proyek
    Semua konsep Bab I sampai XIV dirakit menjadi satu aplikasi SIP-USG utuh lengkap dengan dokumentasi dan demonstrasi.

Cara belajarnya

  • Tulis kode Java langsung di browser, tanpa instal apa pun, dan lihat hasilnya saat itu juga.
  • Tiap bab punya tantangan koding yang diperiksa otomatis, dan sebagian bab punya praktik dua bagian.
  • Kerjakan dengan urutan bebas; progresmu tersimpan dan bisa dijadikan laporan PDF.
