Algoritma dan Pemrograman dengan Python

Fondasi berpikir komputasional dengan Python. Tulis kode langsung di browser dan lihat hasilnya saat itu juga.

Mulai belajar (perlu masuk)

Isi mata kuliah: 14 bab

  1. Bab 1: Fondasi algoritma dan Python
    Algoritma adalah urutan langkah yang bisa diikuti mesin. Python dipakai karena mudah dibaca dan banyak dipakai di dunia kerja.
  2. Bab 2: Variabel, tipe data, operator
    Variabel adalah kotak bernama yang menyimpan nilai. Angka bulat, pecahan, teks, dan benar-salah punya aturan hitung masing-masing.
  3. Bab 3: Flowchart, pseudocode, penelusuran
    Gambar dulu alurnya sebelum mengetik kode. Flowchart memakai simbol baku, pseudocode memakai kalimat terstruktur, penelusuran menjalankan rancangan dengan tangan.
  4. Bab 4: Percabangan
    Program memilih jalan dengan if, elif, dan else. Indentasi menentukan baris mana yang ikut dalam blok.
  5. Bab 5: Perulangan
    for dipakai saat jumlah ulangan pasti, while saat bergantung pada syarat. Waspadai perulangan yang tidak pernah berhenti.
  6. Bab 6: List satu dimensi
    List menyimpan banyak nilai sekaligus. Akses lewat indeks, ambil sepotong dengan slicing.
  7. Bab 7: Nested list dan string
    Tabel di Python adalah list di dalam list. String bisa dipecah, disatukan, dan dirapikan.
  8. Bab 8: Fungsi dan pemrograman modular
    Fungsi memecah program jadi bagian kecil yang bisa dipakai ulang. def, parameter, dan return adalah kuncinya.
  9. Bab 9: Kelas, objek, referensi
    Kelas menyatukan data dan fungsi yang berhubungan. Objek adalah hasil cetakan kelas; menyalin variabel belum tentu menyalin objeknya.
  10. Bab 10: Berkas dan File I/O
    Data di variabel hilang saat program ditutup. Berkas menyimpannya; mode w menimpa, mode a menambah.
  11. Bab 11: CRUD sederhana
    Create, Read, Update, Delete adalah empat operasi yang ada di hampir semua aplikasi data.
  12. Bab 12: Linear dan binary search
    Linear search memeriksa satu per satu. Binary search membelah dua, tetapi datanya harus terurut.
  13. Bab 13: Sorting dan pengantar Big-O
    Bubble sort menukar tetangga; selection sort memilih yang terkecil. Big-O mengukur bagaimana jumlah langkah tumbuh.
  14. Bab 14: Rekursi dan proyek akhir
    Fungsi yang memanggil dirinya sendiri harus punya base case. Bab ini juga menutup proyek kelompok.

Cara belajarnya

  • Tulis kode Python langsung di browser, tanpa instal apa pun, dan lihat hasilnya saat itu juga.
  • Tiap bab punya tantangan koding yang diperiksa otomatis, dan sebagian bab punya praktik dua bagian.
  • Kerjakan dengan urutan bebas; progresmu tersimpan dan bisa dijadikan laporan PDF.
